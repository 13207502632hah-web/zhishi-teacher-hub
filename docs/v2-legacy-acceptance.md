## API 验收规则

- 每次冻结或候选发布前运行 `pnpm api:inventory`，不得出现无法解释的新路由或无任何
  页面/测试引用的写接口。
- `/api/v2/*` 必须执行权限、幂等、Schema 校验和审计；私有文件只通过鉴权接口读取。
- 已废弃业务 API 直接退役；新业务规则只进入版本化 V2 服务层，不保留兼容桥接。
- 小程序不得复制教师端规则，客户端旧路径只在 `mini-program/utils/api.js` 内集中映射。
