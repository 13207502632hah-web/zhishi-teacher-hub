# 知师研室 2.0 候选版交付说明

更新日期：2026-08-11

## 当前结论

本仓库已经形成可运行的 V2 候选环境，但尚未达到统一生产切换条件。智能课表、
智能题库、全局助手、待确认中心、任务与审计契约、学生/家长小程序 V2 接口，
以及学生/班级/课时、组卷、作业批改、学情、评测运营、资源、财务核对和系统设置
都已经有 V2 原生工作台，不再从 V2 模块入口跳回旧页面。

题目待校对、学生/班级/课时/试卷详情、测评成绩表、答题卡逐题校对、作业附件与
批注/语音批改、财务重算审批、反馈反向建课审批和学年晋升/安全撤销等深层工作流
已经进入 V2。课表与题库导入已经接入带租约、自动重试、取消和定时接管的后台消费者；
2,000 行课表与 50,000 题本地规模门禁也已通过。尚未完成的是有标注的真实图片/PDF
OCR 准确率验收、独立测试环境逐角色动态越权验收、微信体验版真机验收和 iOS
签名/TestFlight 验收，因此仍不能视为统一切换完成。

因此本版本只允许内部测试，不执行生产部署、旧站只读切换或微信正式审核。

## 已实现边界

- V2 App Shell、响应式布局、命令面板、AI 助手入口和待确认中心。
- D1 V2 任务、事件、审批、幂等、AI 运行、课表导入、题库向量、搜索反馈与
  FTS5 索引；R2 保存导入原件。
- D1 后台任务租约与每分钟消费者：两个消费者并发领取，超时任务可重新接管，失败
  按指数退避且最多自动尝试 3 次；原文件保留在 R2，可取消并从原文件重试。
- `JobState`、`ApprovalState`、`ImportRowState`、`SearchMode` 共享契约；所有
  核心写入使用稳定 `operationId`。
- OpenAI-compatible 多模型路由、结构化输出校验、模型故障切换、输入匿名化和
  模型/提示词/置信度/依据/采用结果追踪。
- 作业提交支持证据约束的 AI 批改草稿；答题卡支持视觉模型重新识别。两者均在请求
  返回后继续处理、允许取消，并且只能填充可编辑草稿，不能直接确认成绩。
- XLSX、CSV、图片、PDF 课表识别，逐行校对、身份匹配、冲突检查、失败续跑、
  幂等确认与 24 小时安全撤销。
- Word、PDF、图片、XLSX、CSV 题目导入，AI 拆题与待校对；关键词、结构化、
  本地语义向量、可选外部向量索引和模型重排的渐进式混合检索。
- 审批通过后仅允许白名单动作执行；课表调整、题库转正、作业发布、反馈发送、
  试卷草稿、备课草稿和分析报告都保留审批人与原始建议。
- 小程序业务请求统一改走 `/api/v2/mini/*`，一期页面注册仅保留学生和家长能力，
  包含登录、绑定、作业、提交、订正、听写、班级资料、家校消息回执、反馈、文件、
  进度与同步接口。
- 教师网站新增跟读与听写、班级网盘、课堂工具箱和家校消息；班级资料与家校消息都先
  建立草稿，经主教师批准后才进入小程序。家校消息分别记录打开已读和主动知晓回执。
- PWA 可从 iPhone/Android 添加到主屏幕并直达 `/v2/record`；支持移动记录新增、
  编辑、删除、共享审批、弱网发件箱与跨设备版本冲突保留，恢复联网后通过幂等接口同步。
- 原生 iOS 17+ SwiftUI 客户端源码位于 `ios/`，包含登录、今日概览、移动记录和
  离线发件箱，以及课时关联、编辑/删除、冲突另存、服务器安全切换和 Apple 隐私清单；
  它与网页共用 `/api/v2/mobile/*`。
- 移动记录使用 D1 版本号和变更游标；共享给学生/家长前进入待确认中心，确认后才
  产生小程序同步事件，三端不会复制业务规则。
- 学生、班级、近 60 天课时、作业、提交批改、试卷选题篮、学情反馈、反思、资源和
  财务对账已直接读取 `/api/v2/*`；作业发布、批改确认、反馈发送和财务入账进入待
  确认中心，结算执行前会重新计算规则、出勤与指纹。
- 测评与考试项目原生成绩表、答题卡逐题校对、反馈反向解析、Apple 日历私密订阅
  和学年晋升快照已进入 V2 教学运营工作台；正式测评完成、答题卡入成绩、反向建课
  和学年晋升全部进入待确认中心，执行时再次校验业务快照。已确认的晋升在 24 小时
  内可以申请安全撤销，仍需主教师批准，并会阻断晋升后发生过变化的学生档案。
- 作业草稿支持图片、语音、视频、PDF 和 Word 附件；教师可读取学生提交附件并附加
  定位批注、语音或图片批改，审批后才同步学生与家长。
- 试卷详情支持学生版、教师版、答案版、解析版 Word 鉴权导出，并可用系统打印保存
  PDF；导出文件写入 R2 和导出任务记录，不产生公开直链。
- V2 系统设置提供成员与角色、AI 多模型路由状态和审计记录；API 密钥只判断服务器
  是否已配置，不读取或回显正文。AI 功能不设置费用或 token 上限。
- 助教使用独立密码与可撤销会话登录；主教师逐班授权。助教可以准备草稿和待确认项，
  不能查看未授权班级，也不能批准正式动作、进入财务或系统设置。

## 环境与密钥

本地 V2 AI 使用被忽略的 `.env.local`，至少配置：

```dotenv
AI_V2_ENABLED=true
OPENAI_API_KEY=<local-secret>
OPENAI_BASE_URL=https://opencode.ai/zen/go/v1
```

真实密钥不得进入 `.env.example`、提交记录、构建产物、日志或测试快照。内部测试
环境应使用 Cloudflare Secret，并单独创建空 D1、R2、向量索引和任务环境；不能
把当前生产 D1/R2 直接绑定给 V2 候选部署。

## 已完成的本地验收

- OpenCode 兼容接口真实调用成功，结构化响应写入 AI 运行记录，并生成受控审批项。
- 课表 CSV 已完成上传、两行对账、幂等确认、重复请求验证和安全撤销验证。
- 题库 FTS5 已索引本地 40 道样题，关键词与渐进式混合检索返回命中原因和分项分数。
- 50,000 题规模候选补齐耗时 2,330.65ms，分面筛选 345.11ms，重复题 Recall 1.0、
  Precision 0.9231；均通过 2.5 秒、600ms 和 Recall@20 0.95 的显式门禁。
- 10/100/500/2,000 行课表规模门禁全部通过；2,000 行对账 2,000/2,000，中断后
  续跑 860 行，重复执行仍保持 2,000 行，安全撤销 2,000 行。
- 后台任务真实 SQLite 契约已验证独占租约、租约过期接管、指数退避、3 次上限和
  排队任务即时取消；助教凭据、会话撤销和班级授权也通过真实 SQLite 契约测试。
- 三端移动记录已完成真实端到端回归：iOS 来源经 `/api/v2/mobile/*` 写入后可由网页读取；
  草稿和待确认状态不会下发小程序；主教师批准后只向指定角色产生一次增量事件，学生
  专属记录不会被已绑定家长收到，重复审批不产生重复事件。
- 今日教学闭环端到端回归覆盖 16 个业务模块、67 项动态检查，合成账号、测试记录、
  临时变量和本地服务均在结束时清理。
- 生产构建、TypeScript、Lint、399 项自动化测试和小程序专用检查通过；API 清单为
  187/187 有测试或脚本引用，0 个仅有页面调用而没有契约测试。
- 桌面端和 390×844 移动端已检查驾驶舱、题库、课表页面，未发现控制台错误。
