# 自动导入实测记录 — 2026-09-17

## 本轮单一功能点

重复导入仅补齐空字段，不覆盖已有内容、不自动归档本次未识别到的旧题；继续自动入库，不引入人工复核门槛。

发现：同一文件指纹只能证明文件一致，不能证明解析完整，也不能证明题目从未被教师编辑。此前同源刷新路径可能覆盖答案/解析/备注，且在新增题目成功写入前归档旧题。本轮移除此路径，保留精确指纹去重与空字段补齐。

## 修改范围

- `app/api/v2/question-sets/import/route.ts`：统一使用补缺逻辑，移除同源覆盖和自动归档及其报告字段。
- `app/lib/services/question-values.ts`：移除无原始字段快照支持的覆盖函数。
- `app/v2/questions/QuestionLibraryWorkspace.tsx`：移除已废弃的修正/归档结果提示分支。
- `tests/core-logic.test.mjs`：验证自动入库记录的既有答案、解析、备注、分值不会被重导覆盖。
- `tests/question-portable.test.mjs`：以可执行接口测试验证同源部分重导、补缺及再次执行的幂等性。

## 边界与未完成项

- 本地实际入库 62 道不等于线上新增 62 道。
- 本轮未取得用户已登录的线上浏览器控制能力；未核实生产题量或对生产库执行这批导入。
- 已有非空但错误的解析不会再被重导自动覆盖，需依据具体原题证据另行修正；本轮未执行批量历史数据清理或恢复。
- 本轮没有声称实现事务级全任务原子性、完整并发去重或所有格式的解析正确性。
