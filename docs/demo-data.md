# 演示数据说明

## 用途

演示数据用于在空工作区快速体验完整教学闭环，而不必手工录入真实信息。
数据通过“设置 → 演示数据”创建，覆盖班级、学生、课程、课时、题库、组卷、
作业与提交、出勤、课堂记录、反馈、反思、测验与成绩、错题、资源以及结算/套餐等
运营数据。

所有演示记录都会写入 `demo_records` 表，按 `run_id`、`entity_type`、
`entity_id` 追踪；创建入口只处理带“【演示】”标记的数据，不使用真实联系方式。

## 创建与核验

设置页提供两个入口：

- 首次使用：点击“创建综合演示数据”，生成完整演示工作区。
- 已存在演示数据：点击“核验并补齐演示数据”，检查已有追踪记录，并补齐
  缺失或损坏的课时、作业、反馈、题库、组卷和素材。

对应接口为 `POST /api/settings/demo`。重复执行是幂等的，不会重复堆积；
接口返回 `mode` 与各类别数量摘要，写操作会进入审计日志（`seed_demo`）。
当前演示场景版本为 `demo-comprehensive-v2`。

## 清除

“清除演示数据”只删除由 `demo_records` 追踪的记录及其依赖数据，真实教学记录
不受影响。操作要求：

1. 在弹窗中输入指定确认文字“清除演示数据”。
2. 再次确认后提交，对应接口为 `DELETE /api/settings/demo`。
3. 完成后写入审计日志（`clear_demo`）。

若工作区中没有任何可清除的演示记录，接口返回 404 并在页面提示。

## 边界与注意事项

- 演示数据不能替代生产数据。上线前应清除演示数据，或使用独立环境，避免把
  “【演示】”记录当作真实学情。
- 导出备份会包含演示数据。核对备份或迁移数据时，注意区分“【演示】”标记。
- “删除全部教学数据”（`DELETE /api/settings/data`，确认文字“删除全部教学数据”）
  会连同 `demo_records` 一并删除，但保留账号与操作日志；该操作不可恢复。
- 浏览器自动化测试不执行真实删除；演示数据接口的清除逻辑仍受权限、确认文字
  和审计日志约束。

## 测试与合成数据

- `scripts/teaching-loop-e2e.mjs` 会在本地 D1 创建演示数据并跑通完整教学闭环，
  验证重复创建不堆积、演示清除不影响真实数据，结束后清理测试数据并写入
  `outputs/teaching-loop-e2e.json`。
- `tests/core-logic.test.mjs` 与 `tests/settings-redesign.test.mjs` 会校验演示
  接口使用 `demo_records` 追踪、清除时删除 `demo_records`、页面提供
  “核验并补齐演示数据”与“【演示】”标记等契约。
