## 2. 产品边界与角色

| 角色 | 使用端 | 权限边界 |
| --- | --- | --- |
| 主教师 | 网站、PWA、iOS | 查看与管理全部教学数据；批准正式发布、发送、入库、结算与批量变更 |
| 助教 | 网站 | 仅访问获授权班级；可准备草稿和待确认项；不能批准、查看财务或系统设置 |
| 学生 | 微信小程序 | 仅查看本人已发布内容，提交作业、订正、查看反馈、错题与进度 |
| 家长 | 微信小程序 | 仅查看已绑定孩子且经教师发布的内容；支持多孩子切换与允许范围内代交 |
| 公开访客 | 网站公开页 | 仅查看公开资源、政策和帮助；不能读取私人教学数据 |

## 4. 智能化能力

- AI 支持课表视觉识别、题目拆分与结构化、混合检索意图解析、相似题、组卷建议、批改草稿、错因归纳、反馈草稿、学情分析、教学反思和日常驾驶舱建议。
- 模型按视觉、推理、Embedding 与重排能力自动路由，故障时切换；不按费用或 token 限制教学能力。
- 所有结构化结果执行 Schema 校验，并记录模型、提示词版本、输入摘要、置信度、依据和采用结果。
- 姓名、联系方式与身份字段默认匿名化后再发往外部模型；答题卡等必须使用实名上下文时要求教师单次确认。
- AI 只生成草稿或审批项，不直接修改正式题库、调整课表、发布作业、发送反馈或写入正式成绩。

## 5. 数据、文件与后台任务

- Cloudflare D1 保存账号、角色、班级授权、学生、课时、题库、试卷、作业、审批、任务、审计、同步游标与财务数据。
- R2 保存课表/题目原件、图片、PDF、音频、作业附件、班级资料和导出文件。
- 私有文件统一经鉴权接口读取，服务端在每次访问时重新检查角色、绑定、班级和目标对象。
- OCR、题库导入、Embedding、AI 审核、组卷和学情分析采用可暂停、重试、取消、续跑的后台任务。
- 核心写入使用稳定 `operationId`；任务状态包括 `queued / running / waiting_review / completed / partial / failed / cancelled`。
- 网站、PWA、iOS 和小程序共用 `/api/v2/*` 契约与同一份 D1/R2 数据，不复制业务规则。

## 6. 小程序“来写作业吧”

### 学生与家长页面

- 微信登录与角色绑定。
- 作业首页、作业详情、附件/语音/文字提交、离线草稿、失败续传、重复提交保护。
- 批改结果、教师附件、订正、错题、学习进度与增量同步。
- 跟读与听写、班级资料、家校消息、已读/知晓回执和优秀作业。
- 家长多孩子切换；学生和家长不能访问教师草稿、答案或其他学生数据。
- 一期不开放自由式学生 AI 聊天，只展示教师审核后的建议与讲解。

- 业务接口统一为 `/api/v2/mini/*`，共 18 个路由。
- 正式网站和客户端 API 都配置为 `https://daofazuoye.cn`。
- 正式登录探测已返回业务层 JSON；微信端仍必须把 `https://daofazuoye.cn` 配置为 request 合法域名并用 2.0.5 真机复核。
- 2.0.5 未完成最终审核和正式发布确认；任何情况下不得回发 1.0.0—2.0.4。

## 9. 当前风险与未完成项

1. 本地仍保留旧版页面与未版本化 API；新版主入口已经切换，但旧路径尚未完成物理移除。按照“不维护向后兼容”的决策，正式切换后应继续把 V2 仍复用的旧路由处理器下沉为共享服务，再删除旧页面与旧 API。
2. Chrome 实际页面、浏览器控制台与手机尺寸布局尚未完成本轮复核；不能用静态测试代替。
3. 标准安全扫描工具因中文工作区路径触发 GBK/UTF-8 解码错误，未形成正式扫描报告；这是工具环境故障，不代表安全审计通过。
4. 微信 request 合法域名、2.0.5 体验版登录、学生/家长同步与指定真机矩阵仍需在微信环境内完成最终证据。
5. 真实图片/PDF OCR 95% 标注集、真实答题卡裁切证据、逐角色动态越权与弱网矩阵还需要独立测试环境记录。
6. iOS 仍缺 Mac/Xcode 签名、真机与 TestFlight 验收，不影响本轮网站发布，但影响三端统一交付。

## 11. 运维底线

- 不在代码、日志、文档、构建产物或聊天截图中保存 API Secret、AppSecret、会话密钥或临时绕过令牌。
- 任何正式写入都必须保留操作人、审批人、原始建议、证据、执行时间与稳定 `operationId`。
- 外部模型故障只能切换模型或保留任务，不允许跳过 Schema、匿名化、权限和人工确认。
- 私有文件不生成公开直链；学生退班、家长解绑、会话停用后必须立即失去访问权限。
- 发布时只允许网站 2.0 和小程序 2.0.5；禁止旧版重新上线。
